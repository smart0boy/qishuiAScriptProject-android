# 汽水听歌助手 · 独立安卓版

本目录是原生 Android APP 源代码，与 `qishui_android` 中的 AScript 工程分开维护。独立版安装 APK 后运行，无需另装 AScript；最低 Android 11，使用安卓无障碍服务读取目标页面、截屏和点击，中文文字识别模型随安装包一起提供。

当前版本：**1.0.1**。修复部分广告完成提示附带“关闭、按钮”等无障碍说明时未被识别的问题，优先读取明确的已完成按钮，继续关闭和领奖。升级可直接覆盖安装，保留已有设置。

## 使用流程

1. 安装独立版 APK，打开“汽水听歌助手”。
2. 点击“开启无障碍服务”，在系统的已安装服务中启用“汽水听歌助手”。如系统提示“受限设置”，到本应用信息页按系统指引允许受限设置后重试。
3. 可选允许任务状态通知，以便从通知栏暂停。
4. 首次保持“只识别”，设为 1 轮，保存设置。
5. 打开汽水音乐，手动进入一条奖励广告，点击悬浮“助手”→“屏幕自检”。
6. 自检正常后，从悬浮菜单“重新开始”。确认识别正常，再回设置页关闭“只识别”，试跑 1 轮实际点击。
7. 后续按需要设置 1～50 轮、1～60 分钟。实际权益到汽水页面核对。

首次开启无障碍服务属于安卓系统授权，必须由用户操作。启用服务后会显示可拖动悬浮按钮，无需额外申请“显示在其他应用上层”权限。请勿同时运行 AScript 版或其他会自动点击的工具。

## 功能

- 等待正常广告倒计时，完成后关闭广告、点击领取奖励，并确认下一轮页面。
- 发现直播进入预告时优先取消；已进入直播间时确认直播特征，重新定位右上角 X，返回广告继续原流程。
- 取消与退出前重新核对按钮位置，避免点击已失效的位置。
- 按音量减键、点悬浮菜单或通知中的暂停，可停止当前自动操作；打开设置页会暂停。
- 支持继续任务、重新开始、轮数与时间上限；切出目标应用、熄屏和识别异常时暂停。
- 根据实际屏幕尺寸和识别结果定位，通常无需按分辨率修改坐标。横屏、折叠屏、大字体、显示缩放和新的页面布局仍需验证。

通用默认值为 3 轮、15 分钟、只识别不点击。独立版与 AScript 版的设置各自保存，不自动迁移。广告照常播放和计时，程序不修改会员权益或平台发奖规则。

## 本机识别与日志

安装包包含中文 OCR 模型。应用未申请联网、联系人、位置或通用文件读取权限。无障碍服务仅在目标应用 `com.luna.music` 位于前台时处理页面；其他应用页面不进入文字识别或点击流程。

日志保存在本应用专用目录 `Android/data/cn.qishui.helper/files/logs/`：

- `status.json`：最近任务状态。
- `run.jsonl`：状态变化。
- `actions.jsonl`：实际手势和目标位置；手势完成不代表服务器已发放权益。
- `last_scan.json`、`last-scan.jpg`：手动自检结果。

日志不随源码包分发。应用数据清除或卸载会删除本机记录。

## 构建

需要 JDK 17、Android SDK Platform 35、Build Tools 35.0.0 和 Gradle 8.9。依赖采用 Android Gradle Plugin 8.7.3、随包中文 ML Kit 16.0.1。可在 Android Studio 中打开本目录，或配置 `JAVA_HOME`、`ANDROID_HOME` 后执行：

```text
gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

首次构建需要联网下载依赖，安装后的文字识别在本机进行。调试包输出为 `app/build/outputs/apk/debug/app-debug.apk`。

Windows 下建议将源码解压到英文路径后构建，避免部分 JDK 17 和测试工具在中文路径下无法加载测试类。

发布签名保存在本地 `.private/`，不包含在通用源码 ZIP 中。已有签名用于后续覆盖升级，切勿丢失；重新生成签名后将无法直接覆盖已有安装。没有原签名时，可自行生成签名或构建调试包。签名配置文件格式如下：

```properties
storeFile=.private/release.jks
storePassword=YOUR_STORE_PASSWORD
keyAlias=qishui-helper
keyPassword=YOUR_KEY_PASSWORD
```

保存为 `.private/signing.properties` 后，执行 `gradlew.bat :app:assembleRelease`。请勿将真实密码、签名私钥或个人运行日志提交到公共仓库。
